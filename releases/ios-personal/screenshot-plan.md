# App Store 截图计划

当前候选图由 UI Test 在 Mock 环境自动生成，均为 PNG 且无 alpha：

1. `01-discover.png`：素材发现、搜索、筛选和随机抽卡。
2. `02-material-detail.png`：素材详情与开始训练。
3. `03-record.png`：快速灵感与排练入口。
4. `04-mine.png`：个人资产与历史回看。
5. `05-settings.png`：隐私政策和账号删除入口。

规格：

- iPhone 6.3 英寸候选：1206 × 2622，Apple 当前接受的竖屏规格。
- iPad 13 英寸候选：2064 × 2752，运行于 iPad 时为必需规格。
- 每个设备族最少 1 张、最多 10 张；预览视频可选，最多 3 个。
- 正式截图不得包含调试信息、测试账号隐私、占位内容、透明通道或与正式版本不一致的功能。

正式提交前，用同一 Release 候选构建和预发布数据重拍；产品负责人确认文案与顺序，设计负责人确认品牌和裁切，QA 核对画面对应功能均可访问。
